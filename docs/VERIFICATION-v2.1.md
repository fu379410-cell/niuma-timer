# 2.1 验证记录

## 自动检查

工资与排班、目标库和收入趋势的 42 项测试通过。Vite 生产构建与 macOS arm64 独立应用打包通过。

## 浏览器

- 分别切换亮色、深色与跟随系统。手动选择后刷新仍保留，新开的迷你窗继承当前选择，已打开的迷你窗随主窗切换。
- 模拟系统明暗外观变化。跟随系统时界面同步切换，手动选亮色时维持亮色。
- 检查亮色主窗、迷你窗、账本、打工配置与自定义目标弹窗。390 像素宽的页面无横向溢出。

仓库截图中的工资为演示数据。

## 桌面应用

从 macOS arm64 桌面上的独立应用打开并确认应用版本为 2.1.0。主窗切到深色后，新开的迷你窗使用深色。从迷你窗切至亮色后，应用的本机主题文件记住亮色，重新打开主窗后直接使用亮色。原有排班设置可正常读取。

Windows x64 与 Intel Mac 由 GitHub Actions 打包，实机验证覆盖 macOS arm64。
